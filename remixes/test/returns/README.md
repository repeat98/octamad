# `returns` — scratch: the master strip beside the reverb server

The remix for the return channels' first probe (`docs/proposals/MIXER.md` section 17, stage 2):
MASTER STRIP, OXIDE, REVERB SERVER and SEND, with FX1 cut to FILTER, EQUALIZER, DJ EQ,
PHASER and LO-FI so CHORUS, FLANGER and SPATIALIZER give up their words.

## Status

Builds (`make bus REMIX=returns`): payload A uses 3,413 of 4,060 words, 647 free. COMPRESSOR
and COMB FILTER stay stock. Nothing runs on it yet: no gate, no port run, not flashed. The
return slot itself (an effect chosen from the core's pool, MIXER.md section 17) is not built.
