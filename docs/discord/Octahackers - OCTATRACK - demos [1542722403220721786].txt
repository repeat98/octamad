[08.09.2026 21:31] mrscruff2277
I've been working on a new machine I'm calling DUALBUS. It currently replaces pickup but I'll look into if it's possible to add it as an additional machine instead.

It's intended for doing DJ style transitioning between two configurable buses. Each bus is fed by a configurable selection of other tracks, even if those tracks are muted. The input tracks levels are still respected. Then you have a level control (fully bus A, A + B, fully bus B). A DJ style bass kill control (B fully cut, both fully cut, A fully cut), and a Low mid control for additional shaping. It also has a binary swap control which let's you flip the buses for when you're transitioning eg. from live into a recorded loop.

The nice thing is no configuration is done per track, everything is done on the DUALBUS machine. You can use it like a more flexible master track if you want. Eg. put it on T7, bus into it and then have T8 as a neighbour to have a master with 4 FX slots.

horrible demo and horrible quality bc i had to compress it to fit discord’s file size limit but there are fun things here. 

1. trx b2 from machinedrum successfully ported.

[16.09.2026 09:03] mrscruff2277
Finally finished a v1 of the machine I've built for my own liveset. The overall goal was to streamline DJ style transitioning between a group of live thru tracks and a group of live sampled versions of those tracks. So basically a replacement for the crossfader transition trick that let's you use the crossfader exclusively for effects and builds, even while doing extended transitions between a sampled loop and the next incoming track from your live setup. Also, it can act like a more flexible master track - in my setup it sits on T6 with T7 and T8 as thru tracks meaning I have 6 master effects slots. I don't know when I'll get round to pushing it to github, but if anyone's interested in the idea I can post the mod files here. Full description from Claude below:

-----

DUALBUS — a submix/bus machine for the Octatrack

DUALBUS is a new machine type (it takes the place of PICKUP). Set any track to DUALBUS and it stops being a sound source and becomes a mixer bus: you choose which of the other tracks feed it, and their audio is summed into that track. From there it behaves like any normal track — its own level fader, mute, cue and its own two effect slots — so you can compress, filter or reverb a whole group of tracks at once, mute the group with one button, or cue the group to headphones.

The bus has two sides, A and B, with a DJ-style crossfade and EQ between them. A track can also be set to bypass all of that and stay permanently in the mix.


[16.09.2026 09:03] mrscruff2277
Features:

- Group tracks together. Page 2 gives you two columns, A and B. For each one you pick which of tracks 1–8 feed it.
- Four states per track. Off, crossfaded on A, crossfaded on B, or — by setting it in both columns — always present. An always-present track is added after the crossfade and EQ at full level, so nothing you do with the knobs affects it.
- Process the group. The bus track's FX1 and FX2 slots act on the summed audio, so one reverb or one compressor can serve several tracks instead of one per track.
- Real track controls. Level, mute, solo, cue and scene/crossfader assignments all work on the bus as they do on any track.
- A/B crossfade. The LVL knob fades between the two sides — full left is A only, centre is both at full, full right is B only.
- DJ-style BASS kill. A second-order high-pass at around 200 Hz that swaps between A and B: turn one way to kill B's bass, the other way to kill A's, centre kills both. Matched by measurement to an Allen & Heath Xone:96.
- LO MID dip. A −27 dB bell at ~360 Hz, again matched to the Xone:96, for taking the clash out of one side while the other stays intact. Centre is pass-through, so it's out of the way when you don't need it.
- SWAP. Instantly exchange A and B — everything the knobs are doing to A now applies to B and vice versa. It sweeps rather than hard-switching, so it doesn't click. Always-present tracks are unaffected.
- Send levels follow the source fader. How much a track sends to the bus is set by that track's own level. Muting a source track removes it from the main mix but it keeps feeding the bus, which makes it easy to run a track "into the group only".
- Click-free knobs. Level, bass and low-mid all ramp smoothly, including on FUNC+encoder jumps.
