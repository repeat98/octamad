# `analog-oxide` — Analog BD and OXIDE

The `analog-bassdrum` remix plus the OXIDE tape insert (FX1 or FX2 on any
track). PLATE REV is the one stock effect given up (its DSP region, in front of SPRING's, is where OXIDE is packed).
Built for listening in octemu; not flashed.

Build: `make bus REMIX=analog-oxide`.
