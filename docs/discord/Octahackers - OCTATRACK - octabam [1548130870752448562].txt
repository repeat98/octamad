Yeah the firmware contains the coldfire code and the dsp code and at boot the coldfire loads the dsp code into each core and it runs from there.

The DSP machine code can be disassembled. Each effect is an entry in a dispatch table indexed by the FX id, so we can read a stock effect's code, and we can replace an entry with our own code assembled for the DSP, then rebuild the image.
