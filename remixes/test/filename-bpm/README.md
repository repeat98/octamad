# `filename-bpm` — FORCE FILENAME BPM alone

Jannik Aßfalg's (repeat98) PERSONALIZE checkbox that makes the number in a sample's filename its tempo,
on an otherwise stock image. `modules/filename-bpm/README.md`.

## What is in it

- **FORCE FILENAME BPM** — a ColdFire module, no DSP, no chooser row: the checkbox and its three tempo hooks.

## Status

The hooks run under the ColdFire port (`tools/verify/verify_fnbpm.py`); not on a unit.
