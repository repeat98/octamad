# Machinedrum module

This is the WP-B1 native-machine skeleton. It declares the payload-A
PLATE/SPRING/DARK donor span and the shared-window ranges from
[`layout.py`](layout.py) without carrying Elektron bytes. The remix omits the
bus servers and keeps the stock inserts plus DELAY.

The manifest is a `CF_PATCH` placeholder until WP-B2 connects the user's
Machinedrum update to the build-time extractor. The generic remixer ledger
does not yet arbitrate the shared physical window; the plain resource claim
is therefore a review record, not an image-placement proof. No flash image,
sample, `.syx`, or extracted blob belongs in this directory.
