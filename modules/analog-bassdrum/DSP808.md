# DSP 808

The 808 now runs at 44.1 kHz on the same DSP source seam as the 909.
`dsp808.py` supplies original coefficient tables and a reference model;
`bd808.asm` implements the voice. There is no sample playback.

## Reference set and model

Calibration used the 32 files ending in `_Orig.wav` in the user's BassDrum
folder. Tape, TapeSat, `_X`, `_X2`, and unlabeled special-effect recordings
were excluded. The meanings of `_X` and `_X2` are unknown. T and D are
interpreted as tone and decay from their measured effects. The recordings
are mono, 44.1 kHz and appear individually normalized or clipped, so they
cannot establish the instrument's absolute gain across settings.

Body fits across the six D positions give exponential decay times of
approximately 16, 41, 98, 162, 262 and 340 ms. The settled pitch is around
49 Hz, with a small falling excursion whose duration increases with DECAY.
The model interpolates these measurements over the knob. PITCH transposes
around 48.85 Hz at 64; SWEEP 64 uses the measured excursion. TONE adjusts
the trigger/body low-pass from 350 to 2300 Hz. These control mappings are
model choices, not a claim of exact circuit component identification.

The body uses a phase accumulator, an odd degree-nine sine approximation,
a small second harmonic, and a 48-bit amplitude envelope. A damped trigger
oscillator plus an exponential offset models the asymmetric first few
milliseconds. ATK adjusts this transient. A retrigger resets body phase and
excitation, retaining the tone, output LPF and desk filter states. The
trigger path is retired after 4096 samples to avoid truncated damping
leaving a permanent DC residue. The residual attack difference from the
recordings remains a model limitation, especially at the darkest tone.

## Shared output chain

The 808 inserts the 909's **exact assembly blocks** for the desk decode and
sample stage, and reads the same desk and LPF tables. SAT, LOW, HIGH and
LPF therefore have the same laws. The approved `bd909.asm`, `dsp909.py` and
`fit909.json` are unchanged. LPF defaults to 127 (18 kHz) on new assignments
of either model. Existing stored bytes are preserved. LOW/HIGH 64 is neutral.

Both engines plus source glue fit inside the already harvested SPRING REV
region, without consuming another effect or either track FX slot. The
909 retains its X:3100 voice base. Eight 128-word 808 tables occupy
X:3200..35ff; four 64-word 808 voice blocks occupy X:3600..36ff. Both are
inside the previously measured private-X free region ending at X:3940.
The two-instance admission limit remains in place pending hardware timing.

## Verification

`python3 tools/harness/bd808.py --wav` assembles and disassembles the actual
DSP code, then renders it under the DSP host. It checks all trigger offsets,
retriggering, parameter extremes, desk drive/EQ, live parameter changes,
stereo identity and short-tail DC behavior against an independent float
reference. This is an implementation check, not an authenticity score.

`tools/verify/verify_analog_bassdrum_port.py` checks real control transport,
source output, stock AMP/FX and main output. `AB_SAMPLE808=1` selects the
808 reference comparison; `AB_REVERSE=1` swaps models between the two cores.
The panel gate checks new defaults, the MODEL stepped widget, and encoder
editing through the firmware. `make check REMIX=analog-bassdrum` includes
both DSP host gates. Full port/panel checks require `OT_PROJECT`.

Local coefficient fits, comparisons, plots and WAVs remain under
`out/analog-bassdrum/808-reference/` and `out/bd808/`. No source recordings
or firmware bytes belong in a commit. Octatrack hardware is not qualified.

For a reproducible local recording comparison (NumPy/SciPy required):

```
python3 tools/harness/compare_bd808.py /path/to/BassDrum
```

On the supplied 32 originals the median gain-adjusted waveform residual
is -16.6 dB, with no phase alignment. This quantifies a remaining model
difference; it is separate from the much lower DSP implementation residual.
The report records source hashes, decay and pitch measurements, and writes
an original-then-DSP listening pair under `out/bd808/original-comparison/`.
